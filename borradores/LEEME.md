# 📁 Borradores — Reino Silente

Cada escena se guarda aquí en el momento en que se escribe, **antes** de recibir feedback y de publicarse. Así no se pierde aunque cambiemos de sesión.

## Reglas
- Guardar **siempre** el primer borrador nada más escribirlo
- Si hay revisiones, se actualiza el mismo archivo con `v2`, `v3`, etc.
- Cuando la escena está finalizada y publicada en `capitulos/`, se borra (o se archiva) el borrador

## Escenas activas
- `cap2-escena1.html` → ya publicada en `capitulos/`
- `cap2-escena2.html` → **borrador actual aquí abajo** → ya publicada en `capitulos/`
