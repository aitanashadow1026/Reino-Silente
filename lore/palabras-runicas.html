Palabras Rúnicas

Vocabulario documentado del lenguaje rúnico — palabras que los buscadores trazan para hablar con la tierra.

Para conocer las reglas del sistema (alfabeto, cuadrantes, apilamiento y conectores), visita la página del Alfabeto Rúnico.

Monosílabas — 1 capa · dificultad baja

No usan el cuadrante ⑤. Las primeras que aprende un novato.

DA 1 capa

lat. da — imperativo de dare
«Da», «Entrega» — orden de transferencia. Se usa al ceder energía de un cristal a otro.
①: — ②: • ④: | → D(|④) + A(•②)

FAC 1 capa

lat. fac — imperativo de facere
«Haz» — orden de creación o activación. Pone en marcha un proceso.
①: / ②: • ④: ⌣ → F(⌣④) + A(•②) + C(/①)

I 1 capa

lat. i — imperativo de ire
«Ve» — orden de movimiento inmediato. La energía debe desplazarse.
①: | → I(|①)

LUX 1 capa

lat. lux — sustantivo
«Luz» — iluminación doméstica. La runa más común en los hogares de Valdros.
①: ⊐ ②: | ④: / → L(|②) + U(/④) + X(⊐①)

VIS 1 capa

lat. vis — sustantivo
«Fuerza», «Violencia» — impulso brusco de energía. Peligrosa si se traza mal.
①: — + | ②: ⌒ → V(⌒②) + I(|①) + S(—①)

Bisílabas — 2 capas · dificultad media

Usan el cuadrante ⑤ para conectar las dos capas.

IGNIS 2 capas

lat. ignis — sustantivo
«Fuego» — catalizador de calor. Para hornos, fraguas y calefacción.
Capa 1: ①: | + ⌒ → I(|①) + G(⌒①) = IG
⑤
Capa 2: ①: — + | ②: — → N(—②) + I(|①) + S(—①) = NIS

Trisílabas — 3 capas · dificultad alta

Solo buscadores veteranos las trazan con seguridad. Un error en una capa puede tener consecuencias.

SECRETUM 3 capas

lat. secretum — sustantivo
«Secreto» — palabra de apertura del Círculo de la Veta. Solo los miembros la conocen.
Capa 1: ①: — + • → S(—①) + E(•①) = SE
⑤
Capa 2: ①: / + • ④: — → C(/①) + R(—④) + E(•①) = CRE
⑤
Capa 3: ①: \ ②: / ④: / → T(/②) + U(/④) + M(\①) = TUM

VOCATIO 3 capas

lat. vocatio — sustantivo de acción
«Llamada» — runa inicial de todo buscador al entrar al bosque. Detecta la presencia de vetas.
Capa 1: ①: / ②: ⌒ ④: • → V(⌒②) + O(•④) + C(/①) = VOC
⑤
Capa 2: ①: | ②: • + / → A(•②) + T(/②) + I(|①) = ATI
⑤
Capa 3: ④: • → O(•④) = O

EXTRACTIO 3 capas

lat. extractio — sustantivo de acción
«Extracción» — la runa que abre la veta y guía la energía al recipiente. La más usada por los buscadores de oficio.
Capa 1: ①: • + ⊐ ②: / → E(•①) + X(⊐①) + T(/②) = EXT
⑤
Capa 2: ①: / ②: • ④: — → R(—④) + A(•②) + C(/①) = RAC
⑤
Capa 3: ①: | ②: / ④: • → T(/②) + I(|①) + O(•④) = TIO

SCRINIUM 3 capas

lat. scrinium — sustantivo
«Archivo», «Códice» — sella los cristales de memoria del Círculo. Lira la reconoció y memorizó al instante.
Capa 1: ①: — + / ④: — → S(—①) + C(/①) + R(—④) = SCR
⑤
Capa 2: ①: | + | ②: — → I(|①) + N(—②) + I(|①) = INI
⑤
Capa 3: ①: \ ④: / → U(/④) + M(\①) = UM

Pentasílabas — 5 capas · dificultad extrema

Palabras de dos vocablos unidas por el conector ⑤. Solo el Cielo las susurra completas; los buscadores apenas intuyen fragmentos.

VENITE MECUM 5 capas

lat. venite mecum — frase verbal
«Venid conmigo» — la palabra con la que se convence a la Llama de abandonar a su portador. Lira la intuye en el camino a la sierra; es la semilla de la oración de Cielo de ocho capas que se desplegará sola frente al jabalí viejo.
Capa 1: ①: • ②: ⌒ → V(⌒②) + E(•①) = VE
⑤
Capa 2: ①: | ②: — → N(—②) + I(|①) = NI
⑤
Capa 3: ①: • ②: / → T(/②) + E(•①) = TE
⑤
Capa 4: ①: \ ②: • → M(\①) + E(•①) = ME
⑤
Capa 5: ①: / ②: / ④: \ → C(/①) + U(/④) + M(\①) = CUM
